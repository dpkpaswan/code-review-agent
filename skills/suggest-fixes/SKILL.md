---
name: suggest-fixes
description: "Use when proposing concrete remediations for flagged issues."
allowed-tools:
  - Read
  - Write
---

- For each issue, provide Before/After code snippets that are minimal but complete enough to apply.
- Pair each After snippet with a one-line explanation comment describing the fix intent.
- Keep fixes aligned with RULES.md categories and ensure they address the root cause, not just the symptom.
